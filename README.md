# Selenium WebDriver Practice — Sprint 9

Sprint 9 of the QA Engineering bootcamp at TripleTen: web automation testing with Python and Selenium.

---

## About This Repository

This repository holds the practical exercises I worked through during **Sprint 9** of my QA Engineering bootcamp, covering web automation testing with Python and Selenium.

The exercises are small and deliberately focused — each one drills a single technique for automating browser interactions and validating web applications.

---

## Learning Objectives

During this sprint, I focused on practical Selenium automation, including:

- Setting up Selenium WebDriver with Python
- Using different **element locator strategies**:
  - `ID`, `NAME`, `CLASS_NAME`
  - `CSS Selectors`
  - `XPath`
- Working with **explicit waits** (`WebDriverWait` and Expected Conditions)
- Interacting with web elements:
  - Clicking buttons
  - Sending text to input fields
  - Uploading images / links
- Validating UI behaviour with **assertions**
- Handling dynamic content and avoiding flaky tests
- Writing clean, readable, well-commented test scripts
